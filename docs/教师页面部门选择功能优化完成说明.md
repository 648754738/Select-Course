# 教师页面部门选择功能优化说明

## 问题描述
教师页面修改教师时，部门名称不能正常修改。用户选择部门选择器后，无法正确保存部门信息。

## 解决方案
根据用户要求，保持现有表结构不变，使用`department`字段存储部门名称，在前端实现部门ID和部门名称之间的转换。

## 实现方案

### 1. 保持数据库表结构不变
- 继续使用`teacher`表中的`department`字段（varchar类型）存储部门名称
- 不添加新的`dept_id`字段，避免修改表结构

### 2. 前端实现ID和名称转换
#### 2.1 表单绑定调整
- 使用临时字段`tempDeptId`绑定到Treeselect组件
- 表单验证仍然基于`department`字段
- 在提交时将`tempDeptId`转换为对应的部门名称存储到`department`字段

#### 2.2 修改时数据回显
- 在`handleUpdate`方法中，根据`department`字段值查找对应的部门ID
- 将找到的部门ID设置到`tempDeptId`字段，用于Treeselect组件的显示

#### 2.3 数据提交处理
- 在`submitForm`方法中，将选中的`tempDeptId`转换为部门名称
- 将部门名称存储到`department`字段中提交到后端

### 3. 核心代码修改

#### 3.1 表单字段绑定
```html
<el-form-item label="所属部门" prop="department">
  <treeselect v-model="form.tempDeptId" :options="enabledDeptOptions" :show-count="true" placeholder="请选择归属部门" />
</el-form-item>
```

#### 3.2 修改时数据回显
```javascript
handleUpdate(row) {
  this.reset();
  const teacherId = row.teacherId || this.ids
  getTeacher(teacherId).then(response => {
    this.form = response.data;
    // 根据部门名称找到对应的部门ID用于选择器展示
    if (this.form.department && this.deptOptions) {
      const findDeptId = (depts, deptName) => {
        for (let dept of depts) {
          if (dept.label === deptName) {
            return dept.id;
          }
          if (dept.children && dept.children.length) {
            const found = findDeptId(dept.children, deptName);
            if (found) return found;
          }
        }
        return null;
      };
      this.form.tempDeptId = findDeptId(this.deptOptions, this.form.department);
    }
    this.open = true;
    this.title = "修改教师管理";
  });
}
```

#### 3.3 数据提交转换
```javascript
submitForm() {
  this.$refs["form"].validate(valid => {
    if (valid) {
      // 将临时部门ID转换为部门名称
      if (this.form.tempDeptId) {
        this.form.department = this.getDeptName(this.form.tempDeptId);
      }
      
      if (this.form.teacherId != null) {
        updateTeacher(this.form).then(response => {
          this.$modal.msgSuccess("修改成功");
          this.open = false;
          this.getList();
        });
      } else {
        addTeacher(this.form).then(response => {
          this.$modal.msgSuccess("新增成功");
          this.open = false;
          this.getList();
        });
      }
    }
  });
}
```

#### 3.4 表格显示优化
```html
<el-table-column label="所属部门" align="center">
  <template slot-scope="scope">
    <span>{{ scope.row.department || '未分配部门' }}</span>
  </template>
</el-table-column>
```
