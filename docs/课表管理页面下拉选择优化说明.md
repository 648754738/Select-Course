# 课表管理页面下拉选择优化说明

## 优化概述
将课表管理页面中的课程添加和老师添加对话框从手动输入改为下拉列表，显示课程名称、老师名称和学院信息，使选课时使用者更清晰。

## 优化前的问题
1. **用户体验差**：需要手动输入课程名称和教师姓名，容易出错
2. **信息不全**：无法直观看到课程所属学院和教师所属部门
3. **验证复杂**：需要实时验证输入的课程和教师是否存在
4. **易出错**：手动输入可能出现拼写错误或格式问题

## 优化后的改进

### 1. 用户界面优化
- **课程选择**：改为下拉选择框，显示"课程名称 (学院)"格式
- **教师选择**：改为下拉选择框，显示"教师姓名 (部门)"格式
- **筛选功能**：支持输入筛选，快速定位目标选项
- **详细信息**：选项中显示课程类型、部门等详细信息

### 2. 后端API支持
#### 新增接口
- **课程列表接口**：`/course/course/listAll`
  - 获取所有可用课程列表
  - 包含课程ID、课程名称、学院、课程类型等信息
  
- **教师列表接口**：`/system/user/teacherList`
  - 获取所有教师用户列表
  - 包含用户ID、姓名、所属部门等信息

### 3. 前端实现优化
#### 数据结构
```javascript
// 课程选项数据结构
courseOptions: [
  {
    courseId: 1,
    courseName: "高等数学",
    department: "数学与统计学院",
    courseType: "必修课"
  }
]

// 教师选项数据结构  
teacherOptions: [
  {
    userId: 1,
    nickName: "张教授",
    dept: {
      deptName: "数学与统计学院"
    }
  }
]
```

#### 下拉选择组件
```vue
<!-- 课程选择下拉框 -->
<el-select 
  v-model="form.courseName" 
  placeholder="请选择课程"
  filterable
  style="width: 100%"
  @change="handleCourseChange"
>
  <el-option
    v-for="course in courseOptions"
    :key="course.courseId"
    :label="`${course.courseName} (${course.department})`"
    :value="course.courseName"
  >
    <span style="float: left">
      <strong>{{ course.courseName }}</strong>
    </span>
    <span style="float: right; color: #8492a6; font-size: 13px">
      {{ course.department }} | {{ course.courseType }}
    </span>
  </el-option>
</el-select>

<!-- 教师选择下拉框 -->
<el-select 
  v-model="form.teacherName" 
  placeholder="请选择教师"
  filterable
  style="width: 100%"
  @change="handleTeacherChange"
>
  <el-option
    v-for="teacher in teacherOptions"
    :key="teacher.userId"
    :label="`${teacher.nickName} (${teacher.dept ? teacher.dept.deptName : '未分配部门'})`"
    :value="teacher.nickName"
  >
    <span style="float: left">
      <strong>{{ teacher.nickName }}</strong>
    </span>
    <span style="float: right; color: #8492a6; font-size: 13px">
      {{ teacher.dept ? teacher.dept.deptName : '未分配部门' }}
    </span>
  </el-option>
</el-select>
```

## 代码清理工作

### 移除的旧代码
1. **验证方法**：
   - `onCourseNameInput()` - 课程名称输入处理
   - `onTeacherNameInput()` - 教师姓名输入处理
   - `validateCourseNameInput()` - 课程名称验证
   - `validateTeacherNameInput()` - 教师姓名验证

2. **提交表单简化**：
   - 移除了复杂的手动验证逻辑
   - 简化为直接提交（下拉选择已确保数据有效性）

3. **数据属性清理**：
   - 移除了验证状态相关的数据属性
   - 移除了防抖定时器相关代码

## 修改的文件清单

### 后端文件
1. `CourseController.java` - 添加获取所有课程列表接口
2. `SysUserController.java` - 添加获取教师列表接口

### 前端文件
1. `schedule/index.vue` - 课表管理页面主文件
2. `api/course/course.js` - 课程API接口

## 技术特点

1. **数据预加载**：页面初始化时预加载课程和教师数据
2. **筛选功能**：支持filterable属性，用户可输入关键字快速筛选
3. **信息展示**：选项中展示主要信息和次要信息，布局美观
4. **交互反馈**：选择后给予用户明确的反馈提示
5. **错误处理**：对API调用失败进行适当的错误处理

## 后续优化建议

1. **缓存机制**：可以考虑对课程和教师数据进行缓存，减少重复请求
2. **分页加载**：如果数据量较大，可以实现分页或虚拟滚动
3. **权限控制**：根据用户角色显示不同的课程和教师选项
4. **数据同步**：当课程或教师信息发生变化时，及时更新下拉选项
